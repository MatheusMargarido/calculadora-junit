# Calculadora com JUnit

Este projeto é uma calculadora simples desenvolvida em Java com testes unitários utilizando JUnit 5.

## Funcionalidades
- Soma
- Subtração
- Multiplicação
- Divisão (com tratamento de divisão por zero)
- Potenciação

## Tecnologias
- Java 17
- JUnit 5
- Maven

## Como executar os testes
```bash
mvn clean test
